Day 14 – REST API CRUD

Project

Student Management REST API

Objective

To develop a REST API using Python Flask and implement CRUD operations.

Technologies Used

- Python
- Flask
- REST API
- JSON
- Postman

API Operations

Method| Endpoint| Description
GET| "/students"| Get all students
GET| "/students/1"| Get student by ID
POST| "/students"| Add a student
PUT| "/students/1"| Update a student
DELETE| "/students/1"| Delete a student

Learning Outcome

Learned REST API concepts, HTTP methods, JSON data handling, Flask routing, and CRUD operations.

Deliverables

- REST API source code
- Requirements file
- API documentation
- Postman testing screenshots
- GitHub repository
